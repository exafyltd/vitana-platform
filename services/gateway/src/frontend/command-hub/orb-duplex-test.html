ORB Full-Duplex Gate — Device Test

VTID-03706 · answers one question: does this device's echo open the mic gate?

What this is for

Full-duplex voice keeps the microphone open while Vitana speaks. That is only safe if the speaker output, after the browser's echo canceller has done its work, stays below the gate's open threshold. If it does not, Nova hears its own voice and interrupts itself in a loop.

This page runs the exact same gate logic as the ORB widget, against your real microphone and your real speaker, on this device. It talks to no server, writes nothing, and starts no ORB session.

Run it with the speaker at the volume you would actually use, and with headphones off — speakerphone is the hard case.

Run

  1. Echo test — plays a tone, you stay silent. Any gate opening is echo leaking through. Must be zero.
  2. Speech test — plays a tone, you talk over it normally. The gate must open and barge must fire.
  3. Quiet-speech test — same, but say "nein" / "stop" at normal conversational volume, not loudly.

Idle. Grant microphone access when prompted.
