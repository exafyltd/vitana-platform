# Repositories in scope

This project has exactly two repositories. No others exist for it:

- `exafyltd/vitana-v1` (web and mobile app code, cloned at `/projects/sandbox/vitana-v1`)
- `exafyltd/vitana-platform` (backend gateway and services, cloned at `/projects/sandbox/vitana-platform`)

## Rules

1. Before cloning, check whether the folder already exists: `ls /projects/sandbox/<repo-name>` or `git -C /projects/sandbox/<repo-name> status`. If it exists, reuse it. Never clone it again.
2. Do not clone any other repository unless the user names it explicitly.
3. Clone over HTTPS only, and use the folder names above.
