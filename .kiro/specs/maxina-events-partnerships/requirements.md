# Requirements

1. Jovana, Mariia and Dragan maintain every MAXINA event in the native VITANALAND calendar. Events start as private drafts.
2. Editors can preview, publish and withdraw an event. Publishing exposes only the approved partner fields. Internal notes stay private.
3. The branded `/maxina/events` route and an entry link from Commerce let invited partners find the same published schedule.
4. Partners can filter events, switch between a chronological list and a month view, and open a shareable event detail link. Only published events cleared for their access are shown.
5. A partner can propose a contribution for an eligible event (organisation, work email, product or service, quantity or capacity, delivery timing). The server saves the proposal before the confirmation is shown, and a retry never creates a duplicate.
6. Editors see all proposals for an event in a team-only review queue and can update their status. A partner sees only their own proposals.
7. Access requires an active invitation. Revoked partners and unrelated accounts cannot read restricted events or proposals.
8. The page works on desktop and mobile, supports keyboard navigation and uses the official MAXINA logo. Missing dates and photos are shown explicitly.
