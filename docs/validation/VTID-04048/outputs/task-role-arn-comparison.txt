  -> arn:aws:iam::472838866351:role/vitana-ecs-task-role

Both the production gateway (vitana-gateway-awsdr) and the staging
gateway (vitana-gateway) task definitions run under the SAME IAM task
role. GCP's Workload Identity Federation trust binding authorizes that
role ARN as an AWS principal — not a specific ECS service or task-def
name — so the STS token exchange a running production task performs
resolves to the exact same trusted principal staging already uses.
No additional GCP-side grant was made or is needed for this activation.
