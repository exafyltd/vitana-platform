This sandboxed session has no route to registry.npmjs.org, so node_modules
could not be installed and `tsc --noEmit` / `npm run typecheck` / `npm test`
could not be run against the pinned toolchain from this session. An ad-hoc
`npx tsc` in this sandbox resolves an unrelated, much newer global
TypeScript (6.0.2, vs this project's pinned ^5.3.3) that rejects the
repo's own tsconfig.json outright (TS5107, moduleResolution=node10
deprecated) before reaching any project file, so it is not a usable
substitute either.

Verification for this PR is therefore source-level (see
brace-and-field-checks.txt) rather than a green tsc/jest run. Both new call
sites (payload objects) are already typed `Record<string, unknown>`, and
the only new interface member is `sseEverAttached?: boolean` on
GeminiLiveSession (routes/orb-live.ts) -- an optional field added to an
existing interface never narrows or breaks existing usages of that
interface. Requesting CI (which does have registry + toolchain access) be
the actual gate for this PR rather than treating this note as a substitute.
