Note which tests survive every mutation and why. The locale-normalisation test,
the activation-gate parsing test, and the three positive routing assertions
("flag on + covered routes to the cascade", "a live Vertex still wins", "a
Nova-supported language is never diverted") survive all three mutations, because
they must: they assert the mechanism works once switched on, and no mutation to
a REFUSAL path is allowed to move them. A mutation set where everything fails
is not a stronger result — it means the tests are coupled to each other rather
than each pinning one property.

All three mutation runs above were re-executed against the final 11-test suite
rather than being carried over from the earlier 10-test run, so every count
printed here was observed, not inferred.
