Offline Playwright verification (VTID-03707 follow-up — 17px→19px bump) —
local harness only, no network/live-session calls, using the widget's own
pre-existing test helpers _test_showOverlay()/_test_setState() (documented
in-source as the sanctioned way to render the overlay without creating a
real Vertex/Nova session).

Harness: static file server over
services/gateway/src/frontend/command-hub/ (port 8934) plus a second local
static server (port 8935) serving a throwaway harness HTML page that loads
orb-widget.js via <script src>. Playwright (chromium, the pre-installed
/opt/pw-browsers/chromium-1194 build) navigates to the harness page, calls
VitanaOrb._test_showOverlay(), then VitanaOrb._test_setState('listening',
<caption text>) for representative locale strings, at both the 390x844
(mobile) and 1400x900 (desktop) viewports named in this repo's CLAUDE.md
visual-verification protocol.
