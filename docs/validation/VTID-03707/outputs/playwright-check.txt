Offline Playwright verification (BOOTSTRAP/VTID-03707) — local harness only, no
network/live-session calls, using the widget's own pre-existing test helpers
_test_showOverlay()/_test_setState() (documented in-source as the sanctioned
way to render the overlay without creating a real Vertex/Nova session).

Harness: static file server over services/gateway/src/frontend/command-hub/,
Playwright (chromium) loads it, calls VitanaOrb._test_showOverlay(), then
VitanaOrb._test_setState('listening', <caption text>) for representative
locale strings pulled from the new _CAPTIONS dictionary, at both the
390x844 (mobile) and 1400x900 (desktop) viewports named in this repo's
CLAUDE.md visual-verification protocol.
