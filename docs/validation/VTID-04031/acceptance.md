# VTID-04031 — W4g: cost / model badge on every Operator Console turn (gap analysis §3.10 / §4.6)

Context: `docs/OPERATOR-CONSOLE-GAP-ANALYSIS-2026-09-17.md` §3.10 lists "no cost/model display (`meta.provider/model` returned but never rendered)" and §4.6 asks for a cost/model badge. The router already returned `usage` (input/output tokens) and the provider/model that actually served each call; the operator layer forwarded provider/model in `meta` and dropped the usage, so the console could never show what a turn cost — while the agent executor (VTID-04017) already records per-run cost on its outcome rows.

What ships:

- `services/gateway/src/services/operator-turn-cost.ts` (pure): `pricingKeyForModel` (the exact `MODEL_COSTS` key, else a Bedrock inference-profile id reduced to its bare Anthropic name — `eu.anthropic.claude-sonnet-4-6` → `claude-sonnet-4-6`), `turnUsageFields` (tokens + `estimateCost` for one call; an unknown model is `cost_usd: 0, cost_priced: false`, never silently free; no usage → nothing), `summarizeTurnCost` (the plan call and the final call folded: token totals, summed cost, `cost_priced` false if any priced-less call ran, `model_calls`).
- `gemini-operator.ts`: `callVertexWithTools` and `sendToolResultsToVertex` return the router's `usage` (and the final call's provider/model); `processWithGemini` puts `usage`, `cost_usd`, `cost_priced`, `model_calls` and the whole-turn `duration_ms` on the reply `meta` (both paths — with and without a tool round) and the per-call fields on each `model.turn` frame (VTID-04028 sink). No change to the reply text, tool results, `/chat` shape or OASIS events (the `ingestChatMessageEvent` metadata spreads `meta`, so the assistant row now carries the same fields — additive).
- Command Hub: `formatTurnCostBadge(meta)` renders `provider · model · duration · tokens↑ tokens↓ · $cost` (`unpriced` for a model the table does not know; nothing invented when usage is absent); the badge sits on the reply's meta row next to the timestamp with the full breakdown as its tooltip (`describeTurnCost`); the live transcript (`renderOperatorLiveTranscript`) shows each model call as it completes with the same fields and stage; `styles.css` `.message-cost-badge` / `.chat-tool-activity-line--model` plus a phone-width rule that lets the badge wrap under the timestamp instead of clipping; `index.html` cache-bust bumped (the VTID-04028 pin is now "at or after the W4d version").
